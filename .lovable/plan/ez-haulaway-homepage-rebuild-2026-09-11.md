# EZ Haulaway Homepage Rebuild

## Goal
Create a conversion-focused, mobile-first homepage for EZ Haulaway LLC that immediately communicates junk removal in Parker and the Denver metro area, builds trust through local professionalism, and drives free quote or phone/text inquiries.

## Visual Direction
- Premium local-service aesthetic using warm white and neutral surfaces with black typography and controlled red accents.
- Clean, highly readable sans-serif type; bold hierarchy without racing/comic styling in page copy.
- Restrained rounded corners, generous spacing, crisp borders, and minimal motion.
- Real-business tone rather than national-chain polish or generic startup styling.
- Because no logo or photography was supplied, use a clean temporary EZ Haulaway wordmark and clearly labeled photo replacement areas. Do not present generated people, jobs, projects, or reviews as real.

## Homepage Build
- Add a sticky, responsive header with desktop navigation, a compact mobile menu, phone access, and a prominent “Get a Free Quote” action.
- Build the hero around “Junk Removal Without the Headache,” Denver-area positioning, both requested actions, and a large real-job photo slot.
- Add the trust strip with only supported claims: Family Owned, Locally Operated, Free Quotes, Fast Scheduling, and a clearly provisional 5-Star review label only if real review data is later supplied; omit it in this version to avoid unsupported claims.
- Add the six requested service categories and a “View All Services” expansion that reveals the broader supplied service list without leaving the homepage.
- Add the three-step process using the provided language.
- Add a before-and-after layout explicitly labeled for future real job photos.
- Add the four trust reasons with concise, non-guarantee language.
- Add clearly labeled Google review placeholders with no fabricated names, ratings, quotes, or review counts.
- Add the short Ben and Zoe section using only the supplied facts and a clearly labeled photo slot.
- Add the Parker and Denver metro service-area section without inventing cities.
- Add an accessible six-question FAQ.
- Add the final conversion section and compact footer with the supplied 2026 copyright.

## Quote Experience
- Create an accessible quote dialog or drawer available from all primary quote buttons.
- Ask only for name, phone, city or ZIP, removal details, and optional photo upload.
- Keep it frontend-only and clearly explain that submission is a preview until a delivery method is connected; preserve call/text as working `tel:`/`sms:` actions.

## Technical Details
- Define the full semantic color, typography, radius, focus, and subtle motion system in the global stylesheet.
- Keep the homepage as a single semantic route with one H1, correct section heading hierarchy, useful labels, keyboard support, reduced-motion support, and route-specific SEO/social metadata.
- Keep future service and location pages out of scope while structuring content data so those pages can be added cleanly later.
- Use the existing accessible UI primitives where appropriate and avoid backend, authentication, persistence, fabricated claims, or unsupported integrations.

## Validation
- Verify the live homepage at desktop and mobile widths.
- Check the mobile menu, FAQ, service expansion, quote experience, phone/text links, upload control, and form validation.
- Confirm no placeholder template remains, no unsupported facts appear, and no visible overlap or clipping occurs.
